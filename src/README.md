# Source Code

Reusable project logic lives under `src/neighborhood_twin/`. The source layout prevents accidental imports from the repository root and encourages notebooks, tests, scripts, and the application to use the same package.

The package will be built in vertical slices. A folder is added when its first tested module is implemented, not merely to make the tree look complete.

See [neighborhood_twin/README.md](neighborhood_twin/README.md) for the planned module boundaries.
