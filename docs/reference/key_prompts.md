# Key Prompt Log

This file is reserved for a very small number of high-quality, standalone prompts. It is not a conversation history, decision log, or record of every time AI contributed to the project.

## Saved prompts

None yet.

## Admission standard

A prompt belongs here only when all of these are true:

1. It was deliberately written as a standalone instruction, not extracted or reconstructed from a conversation.
2. It clearly states the objective, relevant project context, important constraints, expected output, and quality standard.
3. It is specific enough that reusing it could produce another meaningful and reviewable project artifact.
4. It addresses a high-leverage task such as foundational architecture, a major analytical design, or diagnosis of a difficult project-wide failure.
5. Its value extends beyond a single small edit, file, formatting change, or routine implementation step.
6. The project author has reviewed it and considers the prompt itself worth preserving.

Do not save conversational excerpts, surrounding discussion, assistant responses, course instructions, repository housekeeping, status requests, ordinary debugging, or prompts reconstructed after the work was completed. A prompt should be excluded whenever there is doubt. The final project may contain only one or two saved prompts, and it is acceptable for this log to remain empty.
