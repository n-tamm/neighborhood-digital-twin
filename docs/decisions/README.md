# Architecture Decision Records

Use a short decision record when a choice changes scope, data meaning, a shared contract, or the deployment architecture. Examples include selecting the canonical geography, changing a target definition, choosing the champion model, or replacing the public host.

Name records in order:

```text
0001-canonical-tract-geography.md
0002-forecast-origin-policy.md
```

Copy [0000-template.md](0000-template.md), state the decision and date, and keep the reasoning concise. A superseded decision remains in the history and links to its replacement.
