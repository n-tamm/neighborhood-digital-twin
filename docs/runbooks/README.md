# Runbooks

Runbooks are operational, step-by-step instructions for tasks that must work under time pressure or be handed to another contributor.

Available now:

- [Local environment setup](local_environment.md)

Add these runbooks when the corresponding process is executable:

- pilot data rebuild;
- Databricks workspace and job setup;
- model training and approval;
- serving-bundle build and validation;
- Streamlit deployment and rollback;
- GitHub Pages publication;
- final reproducibility run;
- troubleshooting missing data, failed jobs, and incompatible bundles.

A runbook should list prerequisites, commands, expected outputs, validation checks, rollback steps, and the owner. Architecture explanations belong elsewhere.
