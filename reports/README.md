# Reports

This folder contains the written report and the figures and tables generated for it. It may also contain the required video or poster materials once the team chooses the submission format.

The [AI usage appendix](AI_USAGE_APPENDIX.md) records the required AI workflow diagram, models and available parameter values, prompt-composition approach, actual prompt example, and actual output-evaluation example. It is required because AI has contributed to this project; it is separate from the optional full prompt log.

Planned areas:

- `generated/`: figures and tables created by code;
- `drafts/`: working report text and review copies;
- `presentation/`: the selected video or poster materials and demonstration script;
- `release/`: final submission-ready exports.

Generated outputs are ignored by default until the team intentionally approves a small artifact for version control. Every reported figure and table must be generated by code, have a reproducible command and source-data version, and be discussed in the report. The final report must contain at least three original, legible data visualizations.

The shared visual-EDA pipeline writes its canonical PNGs to the managed Unity Catalog
`neighborhood_twin_gold.eda_figures` volume and records the current matched set in
`gold_eda_figure_manifest`. Copy only reviewed figures into `reports/generated/` when assembling a
specific report draft; do not treat a local export as the source of truth.

See [EDA_FIGURES.md](EDA_FIGURES.md) for the current build, figure inventory, reproduction command,
and export instructions.
