# Reports

This folder contains material prepared for evaluation or communication: generated figures and tables, report drafts, poster assets, demo scripts, and release notes.

Planned areas:

- `generated/`: figures and tables created by code;
- `drafts/`: working report text and review copies;
- `presentation/`: poster, slides, and demonstration script;
- `release/`: final submission-ready exports.

Generated outputs are ignored by default until the team intentionally approves a small artifact for version control. Every final figure should have a reproducible command, a source-data version, and a caption that states what the viewer should and should not infer.
